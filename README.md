# Disha & Sudip — Premium GSAP Wedding Invitation

Mobile-first static wedding invitation with a watercolor/editorial aesthetic.

## Stack
- HTML5
- CSS3
- JavaScript
- GSAP 3 + ScrollTrigger
- Google Fonts
- No backend required

## Important customization
Open `script.js` and edit the CONFIG object:
- wedding dates
- WhatsApp number
- RSVP message

## Assets
`assets/hero-watercolor.png` is the generated watercolor reference artwork used as a visual base for the hero/venue imagery.

For the production version, replace the gallery gradients with the couple's real photos and replace the hero artwork with a properly licensed/commissioned illustration if the client wants the characters to look like the couple.

## Music
Put the wedding song at:
`assets/music.mp3`

The music only starts after the guest taps the music control because mobile browsers generally block autoplay audio.

## Run
Open `index.html` or use VS Code Live Server.

## Free deployment
This is a static site and can be hosted free on Cloudflare Pages or GitHub Pages. A custom domain is optional.
